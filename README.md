## Engineering Principles

- **Keep it simple:** choose the smallest architecture that satisfies real requirements.
- **Security by design:** enforce authorization and protect trust boundaries.
- **Evidence over claims:** distinguish executed tests from planned checks.
- **Automate meaningful checks:** use CI/CD to prevent regressions and unsafe releases.
- **Build for maintainability:** prioritize readable code, explicit contracts, and useful documentation.
- **Measure before optimizing:** performance improvements should be supported by evidence.
